macOS

skhd drives the keys · wmctl drives the daemon · press Esc to close

Focus

Focus left / down / up / right⌘⌥ + H/J/K/L
Focus (arrow keys)⌘⌥ + ←↓↑→

Move windows

Swap left / down / up / right⌘⌥ + ⇧ + H/J/K/L

Resize

Grow/shrink along axis⌘⌥ + ⌃ + H/J/K/L
Step is 5% of the split

Workspaces

Go to workspace 1–9⌘⌥ + 1–9
Send window to workspace⌘⌥ + ⇧ + 1–9

Window

Toggle floating⌘⌥ + F
Toggle split direction⌘⌥ + S
Close window⌘⌥ + Q
Force retile⌘⌥ + R

Help
